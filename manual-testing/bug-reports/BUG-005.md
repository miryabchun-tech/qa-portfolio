# BUG-005 — Dynamic Catalog Lazy Load prevents reaching the bottom of the page

## Environment

- Application: SauceDemo
- User: `problem_user`
- Browser: Google Chrome
- Page: Dynamic Catalog - Lazy Load

## Preconditions

User is logged in as `problem_user`.

## Steps to Reproduce

1. Open SauceDemo.
2. Login with `problem_user`.
3. Enter password `secret_sauce`.
4. Open `Dynamic Catalog - Lazy Load`.
5. Scroll down through the page.
6. Continue scrolling until attempting to reach the bottom of the page.

## Expected Result

The user should be able to scroll to the actual bottom of the page.

## Actual Result

When attempting to reach the bottom of the page, the page jumps back up by approximately one row of product cards.

As a result, it is not possible to reach the actual bottom of the page.

## Severity

Medium

## Priority

Medium
