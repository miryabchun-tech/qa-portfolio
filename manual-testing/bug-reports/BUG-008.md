# BUG-008 — Add to Cart does not work on Product Details page

## Environment

- Application: SauceDemo
- User: `problem_user`
- Browser: Google Chrome
- Page: Product Details

## Preconditions

User is logged in as `problem_user`.

## Steps to Reproduce

1. Open SauceDemo.
2. Login with `problem_user`.
3. Enter password `secret_sauce`.
4. Open the Products page.
5. Open any product.
6. On the Product Details page, click `Add to cart`.

## Expected Result

The selected product should be added to the cart.

The cart badge should be updated accordingly.

## Actual Result

Clicking `Add to cart` on the Product Details page does not add the product to the cart.

High

## Priority

High
