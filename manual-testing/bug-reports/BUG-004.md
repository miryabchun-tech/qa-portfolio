# BUG-004 — Product sorting does not change the order of products

## Environment

- Application: SauceDemo
- User: `problem_user`
- Browser: Google Chrome
- Page: Products

## Preconditions

User is logged in as `problem_user`.

## Steps to Reproduce

1. Open SauceDemo.
2. Login with `problem_user`.
3. Enter password `secret_sauce`.
4. Open the Products page.
5. Open the sorting dropdown.
6. Select a price sorting option.
7. Observe the order of the products.
8. Open the sorting dropdown again.
9. Select an alphabetical sorting option.
10. Observe the order of the products.

## Expected Result

The product cards should be reordered according to the selected sorting option.

## Actual Result

The order of the product cards does not change after selecting different sorting options.

Sorting by price and alphabetical order has no visible effect.

Medium
