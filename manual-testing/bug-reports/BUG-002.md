# BUG-002 — Remove button does not work on Products page

## Environment

- Application: SauceDemo
- User: `problem_user`
- Browser: Google Chrome
- Page: Products

## Preconditions

User is logged in as `problem_user`.

## Steps to Reproduce

1. Open SauceDemo.
2. Login with `problem_user`.
3. Enter password `secret_sauce`.
4. On the Products page, add any product to the cart.
5. Observe that the `Add to cart` button changes to `Remove`.
6. Click the `Remove` button on the Products page.

## Expected Result

The product should be removed from the cart.

The button should change back to `Add to cart`.

## Actual Result

Clicking the `Remove` button on the Products page does not perform any action.

The button remains `Remove` and the product remains in the cart.

The product can be removed successfully from the Cart page.

## Severity

Medium

## Priority

Medium
