# BUG-006 — About page returns 404 before redirecting to SauceDemo home page

## Environment

- Application: SauceDemo
- User: `problem_user`
- Browser: Google Chrome

## Preconditions

User is logged in as `problem_user`.

## Steps to Reproduce

1. Open SauceDemo.
2. Login with `problem_user`.
3. Enter password `secret_sauce`.
4. Open the menu using the three dots icon.
5. Click `About`.

## Expected Result

The About page should open successfully.

## Actual Result

A 404 error page is displayed.

After that, the user is redirected to the SauceDemo home page.

## Severity

Medium

## Priority

Medium

## Status

Open
