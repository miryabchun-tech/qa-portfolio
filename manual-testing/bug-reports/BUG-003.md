# BUG-003 — Add to Cart works only for the first two products

## Environment

- Application: SauceDemo
- User: `problem_user`
- Browser: Google Chrome
- Page: Products

## Preconditions

User is logged in as `problem_user`.

## Steps to Reproduce

1. Open SauceDemo.
2. Login with `problem_user`.
3. Enter password `secret_sauce`.
4. Open the Products page.
5. Click `Add to cart` for the first product.
6. Click `Add to cart` for the second product.
7. Try to click `Add to cart` for other products.

## Expected Result

The `Add to cart` button should work for every product.

Each selected product should be added to the cart.

## Actual Result

The `Add to cart` button works only for the first two product cards.

For the remaining products, clicking `Add to cart` does not add the product to the cart.

High
