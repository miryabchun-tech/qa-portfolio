# BUG-007 — Last Name field incorrectly affects First Name field

## Environment

- Application: SauceDemo
- User: `problem_user`
- Browser: Google Chrome
- Page: Checkout: Your Information

## Preconditions

User is logged in as `problem_user` and has a product in the cart.

## Steps to Reproduce

1. Open SauceDemo.
2. Login with `problem_user`.
3. Enter password `secret_sauce`.
4. Add a product to the cart.
5. Open the Cart.
6. Proceed to Checkout.
7. Enter a value in the `First Name` field.
8. Click the `Last Name` field.
9. Start entering a value in the `Last Name` field.

## Expected Result

The value entered in `First Name` should remain unchanged.

The text entered in `Last Name` should appear only in the `Last Name` field.

## Actual Result

The value in the `First Name` field is cleared.

A character appears unexpectedly in the `First Name` field even though the cursor is positioned in the `Last Name` field.

High
